# 🕹️ PERP Architecture Simulations

This directory contains the baseline Python prototypes for the Planetary Energy Routing Protocol (PERP). These scripts demonstrate how our decentralized AI protocols balance physical energy, material supply chains, atmospheric interventions, global land use, and industrial manufacturing streams.

## 🚀 How to Run the Simulations

You do not need to install any external libraries. These scripts run using standard Python 3. 

Open your terminal and run the scripts from the root directory of the repository:

### 1. Autonomous Grid Management System (Pillar 1)
Models peer-to-peer node communication, physical space solar (SBSP) routing, and virtual data center workload migration.
```bash
python simulations/perp_mesh_simulation.py
```

### 2. Algorithmic Re-Engineering of Materials (Pillar 2)
Models a machine-learning molecular database tracking carbon-negative alternative compounds and calculating long-term structural carbon sequestration values.
```bash
python simulations/material_reengineering.py
```

### 3. Atmospheric Rebalancing Mesh (Pillar 3)
Tracks geoengineering marine and drone sensor telemetry streams, enforcing immutable, automated safety cut-offs during simulated ecological stress.
```bash
python simulations/atmospheric_rebalancing.py
```

### 4. PALO Land Allocator (Pillar 4)
Calculates localized optimization models to transition livestock agricultural land into native forests while maintaining global nutritional safety nets.
```bash
python simulations/palo_land_allocator.py
```

### 5. Automated Circular Economy Marketplace (Pillar 5)
Models automated landfill mining via robotic extraction and uses an algorithmic marketplace to distribute recycled metals and polymers to regional zero-carbon factories.
```bash
python simulations/ace_circular_marketplace.py
```

## 🧪 Run Automated Integration Tests
Verify that all five core simulation engines execute perfectly across the project layout:
```bash
python simulations/test_suite.py
```
